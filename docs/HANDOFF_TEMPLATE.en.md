# Handoff Template

## Purpose

`handoff.en.md` is the short, durable transfer record between loop runs.

## Required Sections

### Run Identity

- job ID
- freeze version
- story ID
- run role
- run attempt

### Status Summary

- exit status
- what was completed
- what remains open

### Key Evidence

- report paths
- log paths
- test result paths
- trace references

### Risks and Blockers

- current blockers
- approval needs
- credential needs
- takeover needs

### Recommended Next Step

- resume builder
- run QA
- enter fixback
- create change request
- wait for owner
- archive

## Quality Rules

- the handoff must be brief and factual
- it must not require session memory to understand the next action
- it must reference stable artifact paths rather than vague descriptions
